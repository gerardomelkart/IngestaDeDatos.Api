# Encabezado del comprobante FESE

`encabezado.base64` contiene en JPEG el encabezado institucional del comprobante de referencia proporcionado para este proyecto (Seguridad y Secretariado Ejecutivo). Se normalizó a 1500 × 241 píxeles para su incorporación como recurso de la API. No contiene datos de entregas, firmas ni información de usuarios.

El cuerpo del PDF se genera con los datos y el comparativo guardados en cada carga. No se incluye el comprobante de referencia ni sus cifras en producción.
